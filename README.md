## 💻 Run the Portfolio Locally

### 1. Clone the repository

```bash
git clone https://github.com/sairoy49/sairoy49.github.io.git
```

### 2. Navigate to the project

```bash
cd sairoy49.github.io
```

### 3. Open the website

Since this is a static HTML/CSS/JavaScript portfolio, no backend installation is required.

You can open:

```text
index.html
```

directly in your browser.

For a better development experience, use the **Live Server** extension in VS Code.
